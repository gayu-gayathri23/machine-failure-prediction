# 🔧 Machine Failure Prediction using Sensor Data

## 📌 Problem Statement
This project aims to develop a predictive maintenance model using industrial sensor data to identify potential machine failures and abnormal operating conditions.

## 📊 Dataset
AI4I Predictive Maintenance Dataset (UCI Machine Learning Repository)

## ⚙️ Tools & Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## 🧠 Models Used
- Logistic Regression
- Random Forest

## 📈 Key Steps
- Data cleaning and preprocessing
- Removal of data leakage columns
- Feature engineering (Temperature Difference)
- Handling class imbalance
- Model comparison and evaluation
- Feature importance analysis

## 🎯 Results
- Optimized for recall to improve failure detection
- Identified Tool Wear and Torque as key predictors
- Selected Random Forest as the final model

## 🚀 Business Impact
The model demonstrates how industrial sensor data can be leveraged to implement predictive maintenance strategies and reduce equipment downtime.
